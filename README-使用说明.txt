视频转MP4 使用说明
==================

这个小工具做这几件事：

  1. 把 MKV / WebM 视频转成 MP4（OBS 以前默认录出来的就是 MKV）。
  2. 把 FLV、TS（还有 .m2ts / .mts）视频转成 MP4（OBS 也能录成这两种格式）。
  3. 把“分片式 MP4”（Fragmented MP4/MOV，下面会解释）整理成普通 MP4。
  4. 可选：把每条音轨另存成单独的音频文件，给只认第一条音轨的剪辑软件（例如剪映）用，见第七节。

画面和声音都不重新压缩，只是换一个“外壳”，所以画质、音质和原来完全一样，速度也很快，
几十 GB 的录像一般几分钟就能转完（主要看硬盘速度）。
原来的文件不会被修改、移动或删除。


一、怎么用（Windows）
--------------------
1. 把下载的压缩包（文件名类似“Remux2MP4-v1.1.0-win64.zip”）右键 → “全部解压缩”，解压到任意文件夹
   （不要直接在压缩包里双击运行）。
2. 打开解压出来的文件夹，双击“视频转MP4.exe”。
   第一次运行时 Windows 可能弹出“Windows 已保护你的电脑”，点“更多信息” → “仍要运行”。
3. 把要转换的文件（或整个文件夹）拖进窗口上方的蓝色框里，
   或者点“添加文件” / “添加文件夹”。文件夹里的子文件夹也会一起找。
4. 点“开始转换”。列表里会显示每个文件的进度和结果。
5. 转完后点“打开输出文件夹”就能看到新的 MP4。双击列表里的某一行可以打开它的转换报告。

小技巧：直接把文件拖到“视频转MP4.exe”的图标上，程序会打开并自动开始转换。


二、转出来的文件放在哪里、叫什么
------------------------------
- 默认放在原文件旁边（同一个文件夹）。也可以在“选项”里选“选择输出文件夹”。
- MKV、FLV、TS 转出来叫“原名.mp4”；分片 MP4 转出来叫“原名_标准MP4.mp4”。
- 如果同名文件已经存在，不会覆盖，会自动改成“原名 (1).mp4”“原名 (2).mp4”……
- 每个文件旁边还有一份“原名.转换报告.txt”，写着每条轨道怎么处理的、检查结果如何。
  报告和“源文件信息.json”里只写文件名，不写完整路径（完整路径里有你的 Windows 用户名），
  可以放心把报告发给别人帮忙看。
- 转换中途会先写成“xxx.partial.mp4”，全部成功后才改成正式名字；
  取消或失败时只会删除这个没写完的文件。


三、旁边多出来的文件是什么（“另存到旁边”）
----------------------------------------
MP4 格式有些东西装不下。为了“一样都不丢”，工具会把它们存成同名文件放在 MP4 旁边：

  原名.3.chi.srt / .ass / .vtt   原来的文字字幕。MP4 里也有一份，但 ASS 特效字幕的
                                  字体、颜色、位置在 MP4 里会丢，旁边这份是完整的。
  原名.4.chi.sup                  蓝光 PGS 图形字幕（MP4 完全装不下）。
  原名.5.eng.mks                  其他图形字幕或特殊字幕的原样副本。
  原名.2.eng.mka                  MP4 装不下的音轨的原样副本（MP4 里放的是转换后的版本）。
  原名_fonts\                     MKV 里附带的字体（ASS 字幕要用）。
  原名_附件\                      MKV 里附带的封面图等附件。
  原名.metadata.txt / .源文件信息.json
                                  MP4 存不下的自定义标签，留个记录。

怎么用这些字幕：
- PotPlayer、VLC、MPC-HC 等播放器会自动加载“文件名开头和视频相同”的字幕，
  只要字幕和 MP4 放在同一个文件夹就行。PotPlayer 里右键 → 字幕 → 选择字幕；
  VLC 里菜单“字幕 → 子轨道”切换。
- 想让 ASS 字幕显示正确的字体：打开“原名_fonts”文件夹，选中字体右键“安装”。
- 普通 MKV/OBS 录像一般没有字幕，所以通常不会多出这些文件。
- 如果你不需要这些，可以在选项里取消“字幕/字体另存到旁边”，报告里会写明丢了什么。


四、OBS 用户请看
---------------
1) 多音轨会全部保留
   OBS 里可以把 游戏声音 / 麦克风 / 音乐 / Discord 分别录到不同音轨（最多 6 条）。
   本工具会保留每一条音轨、它们的顺序、你在 OBS“音频”设置里起的音轨名字，
   以及“只有第 1 条是默认音轨”的标记。
   哪些软件能看到多条音轨：
   - PotPlayer：右键 → 音频 → 选择音轨，可以切换。
   - VLC：菜单“音频 → 音轨”切换。
   - Premiere Pro：会把每条音轨分别导入。如果只看到一条，到“首选项 → 时间轴”
     把“默认音频轨道”改成“使用文件”再重新导入。
   - DaVinci Resolve：会导入全部音轨；如果拖到时间线上只出现一条，检查时间线设置，
     或新建一条时间线再试（OBS 论坛有用户这样解决）。
   - 剪映：我们没有查到官方说明它是否支持多条音轨，没有实测过，不做保证。
     如果导入后只听到第一条音轨，可以勾选“把每条音轨另存成单独的音频文件”（见第七节），
     把需要的音轨文件拖进剪映，和画面开头对齐即可。
   - Windows 自带的“媒体播放器”和大多数手机、网页一般只播放第一条（默认）音轨。

2) 录制中断（OBS 闪退、电脑死机、断电）也能救
   MKV、FLV、TS 和分片 MP4 的好处就是断电也不会全部丢失。本工具会把能读到的部分全部转出来，
   报告里写“录制文件末尾不完整（可能是 OBS 意外退出），已转换到 xx:xx”，
   最后几秒没写完的数据没办法恢复；最后一帧只写了一半时会把这半帧去掉，避免结尾花屏。
   只有文件完全读不出来时才会提示失败，
   并且不会留下垃圾文件。
   如果源文件本身是完整的、只是读取时中途出错（例如移动硬盘接触不良），
   会提示“读取源文件中途出错，输出不完整，请勿删除源文件”，检查连接后重新转换即可。
   OBS 用普通“MP4”格式录制时崩溃，文件里没有目录（索引），本工具无法恢复，会提示并跳过。

3) 大文件
   OBS 录像可能有几十上百 GB。开始前会检查输出盘剩余空间（大约要和原文件一样大，
   再加一点余量；需要重新压缩或另存旁车文件时会多算一些），不够会提示并跳过。输出到 FAT32 格式的 U 盘时，超过 4 GB 的文件放不下，
   也会提前提示。

4) 以后可以不用转换
   本工具适合处理已经录好的文件、批量转换、救回崩溃的录像，以及转完后的逐项检查。
   如果想以后不用手动转换，OBS 本身有两个办法：
   - 设置 → 高级 → 录像 → 勾选“自动重新封装为 MP4”：仍录 MKV（防崩溃），
     停止录制后 OBS 自动再生成一份 MP4。
   - OBS 30.2 及以上：设置 → 输出（输出模式选“高级”）→ 录像 → 录像格式选
     “混合 MP4 / Hybrid MP4”。录制过程中它和分片 MP4 一样防崩溃，正常停止后就是普通 MP4。
     如果 OBS 崩溃，这个文件会停留在“分片”状态——把它拖进本工具就能整理成普通 MP4。
     正常录完的混合 MP4 拖进来会提示“已经是普通 MP4，无需转换”。
     如果你只是想让剪映读到第 2 条以后的音轨，勾选“把每条音轨另存成单独的音频文件”再拖进来：
     MP4 本身不动，只把音轨另存出来（见第七节）。
   （OBS 不同版本的菜单文字可能略有差别，以你的 OBS 界面为准。）


五、什么是“分片 MP4”
-------------------
普通 MP4 的“目录”（索引）只有一份，写在文件开头或结尾，录到一半断电就没有目录，
整个文件打不开。分片 MP4（Fragmented MP4）把视频切成很多小段，每段自带小目录，
所以中途崩溃也能保住已经录下的部分。它常见于：
  - OBS 的“Fragmented MP4 / Fragmented MOV（分片 MP4/MOV）”录像格式，
    以及崩溃后没有收尾的“混合 MP4”；
  - 直播录制工具、网页/流媒体（DASH、CMAF）下载下来的 .mp4 / .m4s 文件。
缺点是很多剪辑软件和播放器打开慢、拖进度条卡，甚至不认。
本工具把它整理成普通 MP4：所有画面、全部音轨、字幕、章节、标签原样搬过去，
一个字节都不重新压缩，并逐包核对数据和原文件完全一致。
程序会自动判断文件是不是分片的：普通 MP4 会跳过，不会动它。


六、FLV 和 TS 录像
-----------------
- OBS 可以录成 FLV 或 TS（MPEG-TS）。拖进来和 MKV 一样处理：画面和声音原样复制，不重新压缩。
- TS 里可以有多条音轨，每条带语言，但没有音轨名字；转出来的 MP4 按原顺序保留全部音轨和语言。
- FLV 只能放一条音轨；OBS 30 以后的“增强型 FLV”里的 HEVC（H.265）和 AV1 画面也能转。
- TS 的时间一般从 1.4 秒左右开始，转出来的 MP4 从 0 开始，各条音轨和画面之间的先后关系保持不变，
  转完会核对（报告里写“音画同步”）。如果 TS 中途时间戳跳变（例如几段 TS 接在一起），
  会按实际内容连续排列，报告里会说明源文件标称的时长不准。
- TS 里的画面和 AAC 声音在 MP4 里要换一种标准的打包方式，所以核对时先把两边统一成同一种形式再逐包比对，
  数据本身仍然逐字节一致。蓝光的 .m2ts / .mts 也可以拖进来。


七、把每条音轨另存成单独的音频文件（剪映等只认第一条音轨时用）
------------------------------------------------------------
默认不勾选。勾选“把每条音轨另存成单独的音频文件”后：
- 每个转出来的 MP4 旁边会多一个“名字_音轨”文件夹，里面每条音轨一个文件，例如：
    1-游戏声音 Game.m4a
    2-麦克风 Mic.m4a
    3-音乐 Music.m4a
  名字是“序号-音轨名”；没有音轨名时用语言（如 2-eng.m4a），都没有时用“音轨2”。
  Windows 文件名里不能用的字符（\ / : * ? " < > |）会换成下划线。
- 不重新编码，格式跟着原来的编码走：AAC → .m4a，MP3 → .mp3，FLAC → .flac，Opus → .opus，
  Vorbis → .ogg，PCM → .wav，AC-3/E-AC-3 → .ac3/.eac3，其他（DTS、TrueHD 等）→ .mka。
  能写音轨名和语言的格式会写进去。转完会把每个文件和源文件里的音轨逐包核对。
- 每个音频文件都从这条音轨的第一个声音开始。在剪映里把它拖到时间线上、和画面开头对齐即可。
  如果某条音轨本来就比画面晚（或早）开始，报告的“注意”里会写，例如：
    “这条音轨比画面晚 0.500 秒开始，剪辑时请对齐（放到画面开始后 0.500 秒的位置）”
  差 0.1 秒以上时，这个文件的结果显示为“完成（有提示）”；更小的差别（例如 0.067 秒）
  也写在报告里，但结果仍是“成功”。
- 已经是普通 MP4 的文件（例如 OBS 32 默认的“混合 MP4”正常录完的文件）：不转换，
  只把音轨另存出来，旁边同样有“原名.转换报告.txt”。不勾选这个选项时，这种文件照旧跳过。
- 命令行用 --export-audio。


八、选项说明
-----------
- 输出到原文件夹 / 选择输出文件夹：转出来的文件放哪里。
- 为冷门音轨额外添加兼容音轨（默认勾选）：DTS、TrueHD、PCM、Vorbis 这几种音轨可以放进 MP4，
  但很多播放器、手机、剪辑软件放不出声。勾选后会在原音轨后面再加一条大家都能播放的副本
  （DTS/Vorbis → AAC；TrueHD/PCM 这类无损音轨 → FLAC 无损），名字是“原名 (兼容)”。
  原音轨仍然保留，并保持原来的默认/非默认设置。OBS 常用的 AAC、Opus、FLAC 不需要也不会加。
  分片 MP4 只做原样整理，不加兼容音轨。
- 字幕/字体另存到旁边（默认勾选）：见第三节。
- 把每条音轨另存成单独的音频文件（默认不勾选）：见第七节。
- 优化网页播放（默认勾选）：把 MP4 的目录移到文件开头，网页、手机、网盘预览可以边下边播，
  剪辑软件打开也更快。代价是写完后要把文件整理一遍。
  我们在固态硬盘上测了一个 2.85 GB 的录像，开不开差别不大，所以默认开启。
  但这一步要把整个文件再读写一遍：几十 GB 的文件放在机械硬盘或移动硬盘上，可能多花几分钟。
  这时进度条会停在 90% 左右，状态显示“整理文件（把索引移到开头，大文件要等一会儿）”，
  程序没有卡死，耐心等它完成即可。不需要网页播放的话可以取消勾选，转换会更快。


九、常见问题
-----------
问：画质会变差吗？
答：不会。能放进 MP4 的画面和声音都是原样复制。只有极少数 MP4 根本装不下的老格式
    （例如 VP8、Theora、WMV、ProRes 视频）才会重新压缩成 H.264（高画质设置；
    10 位或 HDR 的画面会压成 10 位 H.265，保留 HDR），并且原始视频流另存一份 .mkv；
    报告里会明确写出来。OBS 录的视频不会遇到这种情况。

问：转完 MKV 可以删吗？
答：先打开 MP4 看看，再看一眼转换报告的“检查结果”和“注意”部分。没问题再删。
    本工具自己永远不会删除或改动原文件。

问：杜比视界（Dolby Vision）、HDR 会保留吗？
答：HDR10 / HLG 的信息会保留，报告里会显示检查结果。杜比视界我们没有样片实测，
    会尽量原样复制，如果检查发现丢了，报告里会提示，请保留原 MKV。

问：为什么 Windows 自带播放器有的音轨没声音？
答：Windows 11 24H2 全新安装的系统可能不带杜比 AC-3/E-AC-3 解码，DTS 也不支持。
    用 PotPlayer 或 VLC 就能播放，或者保持“添加兼容音轨”勾选。

问：显示“已经是普通 MP4，无需转换”？
答：说明这个 MP4 本来就是标准格式，不需要处理，工具没有动它。
    如果需要把它的音轨一条条另存出来，勾选“把每条音轨另存成单独的音频文件”再转一次。
    如果文件其实是 MKV、只是扩展名被改成了 .mp4，工具会认出来并照常转换。

问：显示失败怎么办？
答：看报告或窗口下方的记录里的原因。常见原因：硬盘空间不够、文件完全损坏、
    文件被别的程序占用（例如 OBS 还在录制）。

问：一打开就提示“找不到 ffmpeg.exe 和 ffprobe.exe”？
答：本工具要靠 ffmpeg.exe 和 ffprobe.exe 干活。程序按这个顺序找它们：
    1) 程序文件夹里的 bin 文件夹（提示框里会写出完整位置）；
    2) 环境变量 MKV2MP4_FFMPEG_DIR 指向的文件夹；
    3) 系统 PATH。
    把这两个文件放进 bin 文件夹是最简单的办法。命令行版找不到时会在错误输出里说明，并返回 3。

问：杀毒软件报毒？
答：本程序用 PyInstaller 打包，个别杀毒软件会误报。程序不联网、不修改系统设置。


十、macOS / Linux 用户
---------------------
压缩包里的“源代码”文件夹可以在 macOS / Linux 上直接用（Windows 也能用）：
1. 安装 Python 3.11 以上和 ffmpeg：
   macOS：brew install python-tk ffmpeg
   Ubuntu/Debian：sudo apt install python3 python3-tk ffmpeg
2. 命令行转换：
   python3 mkv2mp4.py 录像.mkv 另一个文件夹/ -o 输出文件夹 --recursive
   其他参数：--export-audio（把每条音轨另存成单独的音频文件）
             --no-companion（不加兼容音轨） --no-sidecars（不另存字幕字体）
             --no-faststart（不移动索引） --no-verify（跳过逐包比对）
   有文件失败时命令返回非 0。
3. 图形界面：python3 gui.py （macOS/Linux 上不支持拖放，用按钮添加文件）。
